Installing outside Google Play?

Some Android devices may show a Play Protect warning when an app is installed directly from an independent website. That warning can occur because the installation source is outside Google Play; users should review the warning and permissions before installing.

Quick setup
  1. Install the APK or use the Indus Appstore listing.
  2. Open Sentinex and complete the initial setup.
  3. Allow Usage Access when prompted.
  4. Allow Display Over Other Apps when prompted.
