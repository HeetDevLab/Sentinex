Privacy Policy

Sentinex Secure

Effective Date: 17 August 2026

This Privacy Policy applies to the Sentinex Secure mobile application (the "Application"), operated by HeetDevLab ("we", "our", or "us").

This Privacy Policy explains what information is handled when you use Sentinex, why the Application requires certain permissions, how information is stored, and how third-party services used by the Application may process information.

1. Information Sentinex Handles

Sentinex itself does not directly collect or upload personal information such as your name, contacts, precise location, or personal messages to servers operated by HeetDevLab.

Information and data used by Sentinex for its security features may include the applications you choose to protect, security logs, and intruder photos generated by the intruder protection feature.

This application data is intended to remain stored locally on your device and is not uploaded by Sentinex to its own servers.

2. Permissions We Use

Sentinex requires certain Android permissions to provide its security and app-lock functionality. These permissions are used for the purposes described below.

  • Biometric Permission: Used to allow supported biometric authentication, such as fingerprint authentication, for unlocking protected applications.
  • Notification Permission: Used to display relevant security notifications and protection status.
  • Usage Access Permission: Used to determine which application is currently active so Sentinex can apply app-lock protection to applications selected by the user.
  • Camera Permission: Used by the optional intruder protection feature to capture photos after configured failed unlock attempts.
  • Media/Storage Permission: Where required by the Android version, used to save or access intruder photos and related media locally on the device.
  • Display Over Other Apps Permission: Used to display the Sentinex lock screen above a protected application when that application is opened.
  • Foreground Service: Used while Sentinex protection is active to help maintain app-lock functionality in the background.
  • Boot Permission: Used to restore protection-related functionality after the device is restarted.

These permissions are used to provide the corresponding Application features and are not intentionally used by Sentinex itself for unrelated personal-data collection.

3. Data Storage

Sentinex stores application security data locally on the user's device where applicable.

This may include protected-app selections, security logs, application settings, and intruder photos.

Sentinex does not operate its own cloud service for backing up or storing these security records.
