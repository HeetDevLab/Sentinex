# Sentinex Secure

**Sentinex Secure** is an Android app-lock product by [HeetDevLab](https://github.com/HeetDevLab), designed to help users protect selected apps with a lightweight, device-side experience.

## Product features

- **App lock:** protect selected apps with a PIN and supported biometric unlock.
- **Intruder detection:** capture an image after an incorrect PIN attempt when configured and supported.
- **Security logs:** review recorded unlock activity on the device.
- **Device-side operation:** core app-lock functionality is designed for local use.

## Permissions

Sentinex Secure uses Android **Usage Access** to detect selected apps and **Display over other apps** to show the lock interface. Permission availability and background behaviour can vary by Android version and device manufacturer. The app does not use Accessibility Service for its app-lock detection.
